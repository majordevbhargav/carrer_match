return userRepository.save(user);

}

public List<User> getUsers(){

return userRepository.findAll();

}

}

13. Controller layer

Created:

@RestController
@RequestMapping("/api/users")
public class UserController{

@Autowired
UserService userService;

@PostMapping("/register")
public User register(@RequestBody User user){

return userService.saveUser(user);

}

@GetMapping
public List<User> getUsers(){

return userService.getUsers();

}

}

Best practices if doing this again
1. Decide package structure before writing code

Good:

com/careermatch/

controller/
service/
repository/
entity/
config/
security/
dto/

Avoid moving packages later.

2. Commit frequently

After each milestone:

git add .
git commit -m "Backend connected"

Examples:

git commit -m "Added PostgreSQL"
git commit -m "Added user registration API"
git commit -m "Fixed CORS"
3. Use DTOs instead of exposing entities

Instead of:

@PostMapping
public User register(...)

Later use:

RegisterRequest
RegisterResponse
4. Never store passwords directly

Right now:

password = "12345"

Later:

BCryptPasswordEncoder

Store:

$2a$10$kdl39.....

instead of real passwords.

5. Add JWT authentication before building major features

Flow:

Login
    ↓
JWT Token
    ↓
Protected APIs
6. Build features in layers

Good order:

Database
↓
Entity
↓
Repository
↓
Service
↓
Controller
↓
Frontend
↓
AI

Not:

AI first ❌
